# Scope

## Purpose

This lab shows how to fix slow queries on a large logs table:
real problem → measurable results → architectural evolution.
The semantic search chapter shows how to measure search quality with evals.

## In scope

- Query performance and indexing (PostgreSQL)
- Search modes and their measured quality (evals, metrics)
- Bugs that make the results or the measurements wrong
