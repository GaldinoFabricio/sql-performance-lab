# Unmeasured Features

This lab does not accept features that no experiment would measure.

## Why this is out of scope

Each part of the lab exists to produce a measurable result: query timings, index effects, recall, precision, MRR. A feature that nobody could evaluate in an experiment adds code to maintain without adding to the lesson.

If a feature can be framed as a measurable experiment (a hypothesis, a metric, a baseline to compare against), it is in scope. See `SCOPE.md`.
